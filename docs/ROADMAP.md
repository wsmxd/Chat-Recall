# Roadmap

## Phase 0: Planning

- Define product scope
- Document architecture
- Draft Supabase data model
- Draft character card schema
- Draft theme pack schema
- Draft provider adapter interface
- Draft RAG strategy

## Phase 1: Foundation

- Initialize Next.js project
- Configure TypeScript, linting, formatting, and tests
- Configure Supabase project structure
- Add environment variable documentation
- Add basic app shell
- Add provider abstraction with DeepSeek adapter
- Add independent embedding provider abstraction

## Phase 2: Core Chat

- Implement character gallery
- Add default character card structure and instance-provided sample cards
- Implement conversation creation
- Implement streaming chat
- Persist messages
- Add prompt assembly
- Add basic usage and error logging

## Phase 3: RAG and Memory

- Add lore pack tables
- Add document ingestion
- Add chunking and embeddings
- Add vector retrieval
- Add citations
- Add memory summaries and pinned facts
- Add retrieval evaluation tests

## Phase 4: Customization

- Add character editor
- Add card import/export
- Add theme pack support
- Add user custom lore packs
- Add model profile settings
- Add spoiler controls

## Phase 5: Community and Open Source

- Add public/private visibility controls
- Add creator profiles
- Add card and theme sharing
- Add moderation/reporting workflow
- Add contribution templates
- Publish self-hosting guide

## Phase 6: Advanced Roleplay

- Add multi-character rooms
- Add scene director mode
- Add relationship timeline
- Add mood-aware themes
- Add route-aware lore retrieval
- Add prompt benchmark suite
