# Creative Ideas

This file collects product ideas beyond the first implementation pass.

## Roleplay Features

- Scene director: user can steer pacing, location, tension, and narrative camera without breaking character chat.
- Canon slider: choose strict canon, canon-friendly, alternate universe, or freeform.
- Spoiler lock: set progress by episode, chapter, route, or quest.
- Relationship timeline: track trust, rivalry, affection, promises, and unresolved conflicts.
- Memory bookshelf: user can pin, edit, archive, or delete remembered moments.
- Character mood state: cards define emotional states that influence style and theme.
- Multi-character rooms: characters talk to the user and to each other.
- OOC whisper: a separate out-of-character control lane for adjusting the scene.
- Rewrite with intent: ask for a reply to be more shy, colder, funnier, more canon, or more concise.
- Continuity recap: before resuming an old chat, show a diegetic recap written in the character's style.

## Knowledge Base Features

- Lore pack composer: upload notes, tag canon level, set spoiler metadata, and test retrieval.
- Conflicting lore resolver: show when multiple sources disagree.
- Fanon layers: user can enable personal headcanon without mixing it into official lore.
- Route-aware retrieval: visual novels and RPGs can separate route-specific facts.
- Citation drawer: inspect which lore influenced a reply without cluttering the chat.
- Lore health checks: detect chunks with missing spoiler level, bad tags, or duplicate content.

## Creator and Community Features

- Character card forks with diff view.
- Theme pack gallery.
- Prompt benchmark leaderboard for cards.
- Curated indexes for third-party character cards with clear source, attribution, and redistribution metadata.
- Shareable conversation snapshots with private-memory redaction.
- Creator notes displayed separately from hidden system instructions.

## Developer Features

- Provider adapter playground.
- Prompt regression tests.
- RAG retrieval debugger.
- Local mock provider for development.
- Seed data packs for demos.
- Observability panel for latency, retrieval hits, model usage, and errors.

## Monetization-Neutral Ideas

Since this is open source, useful non-lock-in paths include:

- Bring-your-own-key provider settings
- Self-hosting guide
- Optional hosted instance docs
- Exportable cards, themes, lore packs, and conversations
- Transparent cost accounting per provider
